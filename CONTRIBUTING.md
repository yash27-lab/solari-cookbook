# How to help

## Start

1. Fork the repo.

2. Create a short branch for one change.

3. Run `npm install` inside `civra`.

4. Make the smallest clear change.

5. Run `npm run check` inside `civra`.

6. Open a pull request with the problem, the change, and proof that it works.

## Pull request rules

Keep keys and private files out of Git.

Add a test for new behavior.

Do not add payment or final submission without a safety review.

Use simple words in owner facing text.

Keep the owner in control of outside actions.
